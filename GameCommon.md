The GameCommon folder collects a bunch of commonly required application-agnostic utility classes and modules.

See GameCommon\Readme.md  for more details

GameCommon code often relies on and assumes the use of the Antiquated\Pub libraries, see Pub\Readme.md

Changing UIX (GameCommon\UIX): read GameCommon\UIX\UIX.md first. It has the change process and the test harness.
